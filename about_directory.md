# About This Directory
Purpose: Top-level map for the project repository.
Contains: Product code in `src/`, curated documentation in `docs/`, planning and status in `memory_bank/`, phase-local assets in `data/`, and reports in `logs/`.
Start Here: Read `AGENTS.md`, then `docs/component_design.md`, `memory_bank/ARCHITECTURE.md`, and `src/main.py`.
Key Files/Dirs: `configs/` holds runtime config, `tests/` holds executable specs, `scripts/` and `tools/` hold helpers.
Notes: Ignore hidden directories and `external/` unless the task explicitly requires tooling internals or vendor references.
