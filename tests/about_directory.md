# About This Directory
Purpose: Executable specifications for the project behavior.
Contains: Unit and integration tests that mirror source modules plus a local `AGENTS.md` for test-specific rules.
Start Here: Read `AGENTS.md` for testing conventions, then open the `test_*.py` file that matches the source area you are touching.
Key Files/Dirs: `AGENTS.md`, `test_ingestion_*.py`, `test_indexing_service.py`, `test_retrieval_*.py`, `test_answering_service.py`, `test_submission_pipeline.py`.
Notes: This directory should explain expected behavior, not host generated reports.
