# About This Directory
Purpose: Lightweight developer tools that support dataset, workflow, and operator-script operations.
Contains: `goldset_workflow.py` for goldset-related helper work and `operator_context.py` for config-aware path resolution used by numbered shell scripts.
Start Here: `operator_context.py` for shell-script path/context resolution, or `goldset_workflow.py` for goldset tooling.
Key Files/Dirs: `operator_context.py`, `goldset_workflow.py`.
Notes: This directory is intentionally small and tool-oriented rather than part of the main runtime package.
