# About This Directory
Purpose: Operator-facing helper scripts for environment setup, GPU/runtime repair, vendored parser bootstrap, visible-progress model download, config-aware pipeline stages, and targeted maintenance.
Contains: Environment and dependency bootstrap scripts, NVIDIA device-node repair helpers, vendored `opendataloader-pdf` runtime setup, Hugging Face model download/verify helpers, quality gates, and phase-aware corpus/index/submission wrappers with dry-run or preflight support.
Start Here: Use `00_check_env.sh` and `00_repair_gpu_runtime.sh` to confirm host GPU visibility, then `01_install_deps.sh`, `01b_install_opendataloader_runtime.sh` when W4C structural parsing needs the vendor runtime, `02_download_models.sh`, `03_lint_and_test.sh`, `04_parse_corpus.sh --dry-run`, `05_build_indices.sh --dry-run`, and `06_build_submission.sh --preflight` before committing to expensive runs.
Key Files/Dirs: `00_check_env.sh`, `00_repair_gpu_runtime.sh`, `01_install_deps.sh`, `01b_install_opendataloader_runtime.sh`, `02_download_models.sh`, `03_lint_and_test.sh`, `04_parse_corpus.sh`, `05_build_indices.sh`, `06_build_submission.sh`, `07_validate_submission.sh`.
Notes: Prefer `src/main.py` for product-supported flows; these scripts wrap common operator sequences and should stay aligned with config-derived paths, the cached CUDA/NVIDIA dependency strategy, the vendored parser runtime contract, the setuid `nvidia-modprobe` recovery path, and the shared Hugging Face cache.
