# About This Directory
Purpose: Main runtime package for the product implementation.
Contains: The CLI entrypoint plus the ingestion, indexing, retrieval, answering, evaluation, submission, provider, and shared-contract layers.
Start Here: `main.py` for the CLI, then `common/`, `submission/`, and the component directory relevant to your task.
Key Files/Dirs: `main.py`, `common/`, `ingestion/`, `indexing/`, `retrieval/`, `answering/`, `submission/`.
Notes: Ignore `__pycache__/`. For the best reading order across components, see `docs/component_design.md`.
