# About This Directory
Purpose: Final answer construction layer.
Contains: `service.py`, which handles deterministic extraction, free-text answering, evidence normalization, and confidence shaping.
Start Here: Open `service.py`; this directory is intentionally consolidated rather than split into many helper modules.
Key Files/Dirs: `service.py`.
Notes: If you are tracing end-to-end flow, pair this directory with `src/retrieval/` and `src/providers/`.
