# About This Directory
Purpose: Session logs written by agents during task execution.
Contains: Task-scoped subdirectories such as `TASK-W3A/` and some root-level consolidated logs.
Start Here: Navigate by task id if you need historical execution evidence.
Key Files/Dirs: `TASK-W1A/`, `TASK-W2*/`, `TASK-W3*/`, `MEMORY-BANK-SYNC/`, `W3D/`.
Notes: The run-specific subdirectories are archival leaves. Do not read them all; pick the one that matches the task you are investigating.
