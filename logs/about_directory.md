# About This Directory
Purpose: Project and agent logging area.
Contains: `logs/project/` for reusable reports, `logs/agents/` for agent session logs, and a local `AGENTS.md` with logging conventions.
Start Here: Read `AGENTS.md`, then choose `project/` for stable reports or `agents/` for session evidence.
Key Files/Dirs: `AGENTS.md`, `project/`, `agents/`.
Notes: Do not scan every log by default; start from the subdirectory that matches the task type.
